# Launch Video

36-second launch/demo for Agent Failure Lab: a failed session becomes an
autopsy, becomes a benchmark, becomes a passing regression suite.

- Video: `agent-failure-lab.mp4` (1920x1080, H.264, ~4 MB)
- Poster: `agent-failure-lab-poster.png` (also baked as frame 0 of the MP4,
  so it shows as the thumbnail everywhere)

Generated using BRAG.

Source project:
https://github.com/latent-spaces/brag

Render source (plan, composition brief, Hyperframes composition) lives in
`brag-output/` (build working directory, not checked in).

All on-screen data is real: the demo session, the actual
`HALLUCINATED_API` diagnosis (critical step #12,
`redis.invalidateUser()` vs `redis.deleteUser()`), the real commands
(`agentlab promote`, `agentlab run-suite`), and the real suite result
("1 passed, 0 regressions"). Music: "Happy Beats / Business Moves" by
ende.app, SFX: Kenney (both CC0, via the BRAG skill bundle).
